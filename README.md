# AyuGram iOS — GitHub build kit

Этот комплект запускает сборку custom-варианта стороннего AyuGram iOS-порта в GitHub Actions. Он использует ваш Telegram API ID и hash через Actions Secrets; значения не записаны в исходники, README или workflow. Workflow проверяет наличие и формат секретов, не выводя сами значения.

## Функции, добавленные или включённые в iOS-сборке

- Ghost mode: скрытие прочтения, онлайн-статуса, набора текста, записи/загрузки и просмотра историй.
- Локальная история отредактированных и удалённых сообщений, включая поддерживаемые медиа.
- Отдельные переключатели для сохранения удалённых сообщений, истории правок и чатов с ботами.
- Сохранение и пересылка контента из ограниченных чатов, разрешение скриншотов.
- Тихая отправка, автоматический офлайн после отправки, отключение рекламы и предупреждения о ссылках.
- Регулярные regex-фильтры с выбором личных чатов, фильтр Zalgo-текста и настраиваемые метки изменений/удалений.
- Отображение секунд у времени сообщений и скрытие полосы историй над списком чатов.
- Подтверждение перед отправкой голосовых и видеосообщений.
- Скрытие рекомендаций похожих каналов в чатах.
- Скрытие Premium-значка в заголовке чата.
- Темы, фоны и видеообои в custom-варианте.

Это iOS-порт с набором AyuGram-функций, а не полная копия Android/Desktop. AyuSync и Android-службы на iOS в комплект не входят. Исходник порта: [mapix3/AyuGram-iOS](https://github.com/mapix3/AyuGram-iOS), закреплённый commit `2c0193cd9d91e7a9a529c26e47f9e6ebf49c06ec`.

## Как собрать unsigned IPA

1. Добавьте каталог `.github` из комплекта в корень вашего GitHub-репозитория.
2. В `Settings → Secrets and variables → Actions` этого же репозитория добавьте `TELEGRAM_API_ID` и `TELEGRAM_API_HASH` — свои данные приложения Telegram. Не добавляйте их в файлы или сообщения.
3. Откройте `Actions → Build AyuGram iOS custom unsigned IPA → Run workflow`. Bundle ID можно оставить по умолчанию или указать свой.
4. После завершения скачайте артефакт `AyuGram-iOS-unsigned-ipa`. Для установки IPA потребуется подписать её способом sideloading.

Сертификат Apple и Mac для сборки через этот workflow не требуются. Сборка проходит на GitHub-hosted macOS runner. Workflow не запускает проверки/тесты исходного проекта и не публикует релиз.
